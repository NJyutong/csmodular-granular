# CsModular 颗粒合成库

[English](README.md) · **简体中文** · [Русский](README.ru.md)

![宿主系统](https://img.shields.io/badge/Host-gleb812/csmodular-blue) ![许可证: MIT](https://img.shields.io/badge/License-MIT-green) ![Csound](https://img.shields.io/badge/Csound-granular--engine-orange)

面板按操作顺序分区：**1 声源/音色 → 2 颗粒塑形与随机 → 3 立体声输出 → 进阶**。振荡器顶部是波形（0 正弦、1 三角、2 锯齿、3 方波）、音高和颗粒/秒（音高 0 = 220 Hz，即 A3）；采样器顶部是采样槽、采样位置和扫描速度（每秒走过文件的百分比，0 = 停在采样位置，锁定位置会暂停扫描）；冻结器顶部是录入/冻结、回看位置和回看抖动，干湿比与输出电平放在一起。很少影响结果的控制放在最后：振荡器的“相位”和“锁定位置”（对任何周期波形都没有听感影响，保留是为了让旧工程仍能加载）、采样器的“锁定位置”和干声混合、冻结器的中心声像。首次使用可保持这些参数的默认值。

## 第一次使用

刷新应用后，点击右上角“入门指南”，再点击“加载发声示例”。这会载入已连接的“颗粒振荡器 → Outs2”；有现有工程时会先要求确认替换，请提前保存。调低扬声器音量，点击底栏 ▶ 播放。指南中有添加模块、拖线、保存和无声排查步骤。

三个模块的顶部注明各自用途：振荡器无需输入，采样模块要先右键导入 WAV，冻结模块要先连接音频并录入。“颗粒包络”已改为汉宁窗/三角窗选择器。冻结模块可选“录入/冻结”；另外两个模块可选“跟随/锁定”，锁定的是读取位置。点击选择器小箭头切换；已有的旋钮旁插孔仍可叠加调制。

界面会根据浏览器或系统的语言偏好，自动显示简体中文、俄语或英语；其他语言默认显示英语。更改系统语言后，刷新应用即可切换。

颗粒插件源码与 CsModular 宿主应用分别维护在独立仓库中。

## 启动和连接

在插件目录运行 `node scripts/host.mjs dev`，然后打开终端显示的网址。通过补丁加载按钮打开 `examples/granular-demo.json`，或按空格键，从 Granular 库添加模块。

* 将“颗粒振荡器”的左声道输出连接到“颗粒冻结”的音频输入，再将“颗粒冻结”的左右输出分别连接到 Outs2 的左右输入。开启音频播放。
* 先让模块录入几秒音频，将“冻结”选择器切换到“冻结”：环形缓冲停止写入，已有颗粒仍会继续播放。切回“录入”可恢复录制。
* 使用采样文件时，选择采样槽（1–8），右键点击“颗粒采样”模块，选择“导入 WAV”，再将左右输出连接到 Outs2。
* 连线的两个模块必须位于同一层。混合旋钮（冻结器叫“干湿比”，振荡器和采样器叫“颗粒/干声比”）拉满时输出颗粒声；为 0 时输出干声输入。
* 前 12 个旋钮旁的控制插孔可接收调制信号，并与旋钮值叠加。
* 窗函数：0 为汉宁窗，1 为三角窗；该设置会作用于新生成的颗粒。

## WAV 支持范围

单个 WAV 文件最大 256 MiB，时长不超过 5 分钟。每次应用运行最多载入 512 MiB 的 WAV；解码后的单声道采样数据合计不得超过 4,800 万帧。

支持采样率 8–192 kHz、单声道或立体声的 PCM 8/16/24/32 位、IEEE float32/64 和标准扩展 WAV 格式。立体声文件只读取左声道；暂不支持 RF64 和大端序 WAV。

采样槽在本次应用运行期间共享。关闭或刷新应用后，需要重新载入文件。替换采样文件会重启音频引擎，并清空实时录音缓冲。

Csound 负责 WAV 解码和全部音频处理。JavaScript 只负责选择文件、检查文件头、将文件传入 Csound 虚拟文件系统，以及传递界面参数；不会在 JavaScript 中处理颗粒音频。

## 插件开发

在插件目录运行 `node scripts/build-modules.mjs` 生成模块，再运行 `node scripts/install.mjs
` 安装到宿主。完整参数说明和 DSP 架构见英文指南 `README.md`。原创引擎采用 MIT 许可证；参考来源和许可证判断见 `SOURCES.md`。
